# v0.1.0-alpha.2 — Quality hardening alpha

Two files in. Differences out.

This prerelease keeps the same deliberately small product workflow while hardening the comparison engine, privacy invariants and static distribution.

## Highlights

- automatic matching refuses genuinely ambiguous key choices instead of guessing;
- known semantic column conflicts are not paired automatically;
- conservative date normalization with optional Expert Mode date formats;
- expanded parser, normalization, export and mapping regression coverage;
- EN/LV translation-key parity checks;
- privacy/security source-invariant tests;
- 10,000-row performance regression baseline;
- production static CSP with `connect-src 'none'`;
- static-dist verification and high-severity dependency audit in CI;
- stronger modal focus handling and accessible table actions.

## Important

This remains an alpha prerelease. Manual screen-reader, contrast and representative-device walkthroughs still need to be completed before a public stable release.

Use synthetic or non-sensitive sample data when reporting bugs publicly.
