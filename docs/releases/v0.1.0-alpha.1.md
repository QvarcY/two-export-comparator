# v0.1.0-alpha.1 — First functional alpha

Two files in. Differences out.

This prerelease marks the first functional Two-Export Comparator alpha: two CSV/TSV exports can be loaded locally in the browser, matched automatically and inspected through a side-by-side Visual Diff.

## Highlights

- local-only CSV/TSV processing;
- automatic delimiter detection;
- automatic column mapping suggestions;
- deterministic record matching;
- mismatches, missing rows, duplicates and ambiguous keys surfaced explicitly;
- side-by-side Visual Diff;
- CSV result export;
- English and Latvian UI;
- no account or cloud upload required for comparison.

## Important

This is an alpha prerelease, not a stable production release. Automatic mapping and normalization are deliberately conservative and still need broader edge-case coverage.

Use synthetic or non-sensitive sample data when reporting bugs publicly.
